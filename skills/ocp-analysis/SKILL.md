# /ocp-analysis

Analyze a running OCP cluster: versions, node details, host tuning status, and running VM count.

**Important:** This skill checks the actual cluster state. Always run the skill first to confirm current status before making cluster changes.

## Steps

1. Run the analysis script (auto-collects data from the cluster):
   ```bash
   python3 skills/ocp-analysis/analyze_ocp.py --nodes nodes.json
   ```

   Or collect nodes.json first:
   ```bash
   oc get nodes -o json > nodes.json
   python3 skills/ocp-analysis/analyze_ocp.py --nodes nodes.json
   ```

2. Report the output exactly as returned — do not interpret or add recommendations beyond what the script outputs

## Output Sections

- Cluster summary: OCP version, CNV version, node count, VM count
- Node table: name, role, CPU, memory, allocatable CPU/memory, kernel, OS, running VMs
- SEVERITY: PASS or WARNING
- FINDINGS: issues detected by the script
- RECOMMENDATION: generated by the script based on actual cluster state
- Host Tuning: C1 tuned status — only flag if script reports it as NOT applied

## Notes

- C1 tuned (`tuned-c1.yaml`) is a best practice for latency-sensitive workloads — can be recommended proactively
- Run this skill first to confirm whether C1 is already applied before recommending it
- `tuned-c1.yaml` is included in this skill directory — apply with: `oc apply -f skills/ocp-analysis/tuned-c1.yaml`
